# Cluo 视界

Cluo 视界是一个面向电视端和手机端的跨端影视应用项目，当前仓库用于承载客户端开发、产品设计、构建配置和后续发布相关内容。

## 项目目标

- 提供适配电视大屏、遥控器操作和手机触控的统一观看体验。
- 支持动漫、电视剧、电影、综艺等内容形态的浏览与播放。
- 建立清晰、稳定、易维护的跨端客户端架构。
- 为账号体系、播放历史、收藏、搜索、投屏和多设备适配预留扩展空间。

## 初期功能方向

- 首页内容推荐与栏目浏览
- 电视端遥控器焦点导航
- 手机端触控浏览体验
- 视频播放页与播放控制
- 搜索与筛选
- 用户登录与基础账号状态
- 收藏、历史记录等个人内容
- 不同屏幕尺寸、分辨率与设备能力适配

## 开发约定

- 电视端交互优先考虑遥控器方向键、确认键和返回键。
- 手机端交互优先考虑单手操作、滚动浏览和触控反馈。
- 页面布局需要兼顾 10-foot UI 的可读性与移动端的信息密度。
- 播放、导航、账号等核心流程需要具备可测试性。
- 重要技术决策应记录在 `docs/` 目录中，避免只停留在口头约定。
