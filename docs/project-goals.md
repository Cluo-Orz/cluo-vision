# Cluo Vision 项目目标

> 版本: v1.0 | 日期: 2026-07-05

---

## 项目起源

我在家中部署了 Linux 服务器和 NAS 存储，希望打造一个**家庭影院系统**，核心诉求很简单：

> **找片 + 看片，两个动作，一个 App 搞定。**

市面上现有的方案（Jellyfin、Plex、Emby 等）虽然能"看片"，但"找片"环节是断裂的——你需要自己去 PT 站/BT 站找资源、手动下载、手动整理。我希望把这两个环节统一到一个体验里。

---

## 硬件环境

### 电视

- **型号**: FFALCON 鹤7 PRO 25款 85R795C（雷鸟 / TCL 子品牌）
- **系统**: Android 14 + 灵控系统 3.0
- **芯片**: MT9655 四核 A73，4GB RAM + 64GB ROM
- **显示**: 85 英寸 4K MiniLED，Dolby Vision IQ，HDR10+，144Hz
- **网络**: Wi-Fi 6 + 千兆有线

### 服务器

- 本地 Linux 服务器（Debian/Ubuntu）
- NAS 存储（用于存放视频资源）
- 局域网千兆连接

## 核心功能

### 找片 🔍

我不想自己去各个资源站翻找，希望 App 能帮我：

1. **搜索影片** — 输入名字就能搜，不管资源在哪个站
2. **浏览资源站** — 能看到接入的资源站列表（PT 站、BT 站、动漫站等）
3. **一键下载** — 搜到后点下载，后台自动完成（搜索资源 → 添加到下载器 → 下载完成 → 重命名归档 → 入库刮削）
4. **查看进度** — 能看到哪些在下载、下载进度、哪些下完了

### 看片 📺

下载完成后，我希望能像 Netflix 一样浏览和观看：

1. **海报墙浏览** — 电影/电视剧/动漫分类展示，精美海报
2. **详情页** — 简介、演职员、评分、相关推荐
3. **点击播放** — 调起 Yamby（专业 Jellyfin 播放器）进行播放，支持 4K HDR/Dolby Vision、ASS 特效字幕、多音轨切换
4. **进度记忆** — 看到哪了、哪些没看、继续观看（播放进度由 Jellyfin 同步，多端共享）
5. **收藏管理** — 收藏喜欢的、标记已看

> **播放策略说明**：Cluo Vision 不内置视频播放器，而是通过 Android Intent 深度链接调起 Yamby。原因：目前没有任何开源播放器能正确渲染 Dolby Vision，而鹤7 PRO 的 DV 是核心卖点。Yamby + Jellyfin 服务端转码可以保证最佳画质。用户点击播放瞬间切换，看完按返回键回来，体验无感。

这两个核心功能对应两条数据流：

```
找片: App搜索 → 资源站匹配 → 下载器下载 → 自动整理归档 → 媒体库刮削 → 可观看
看片: App浏览媒体库 → 点击播放 → Intent调起Yamby → Jellyfin视频流 → 电视硬解
```

## 内容覆盖

我希望支持的视频类型和来源：

| 类型 | 来源 | 说明 |
|------|------|------|
| **电影** | PT 站（M-Team 等）、BT 站 | 4K 原盘 / 压制，主流电影全覆盖 |
| **电视剧** | PT 站、国内 WEB-DL | 国产剧、美剧、日剧、韩剧 |
| **动漫** | 蜜柑计划、动漫花园、U2 PT | 新番追更 + 老番收藏，这是重要使用场景 |
| **综艺** | PT/BT 站 | 国内综艺 |

## 设计原则

1. **电视优先** — 所有交互优先考虑遥控器操作，手机端适配为第二优先级
2. **离线可用** — 不依赖任何云服务，纯局域网环境可正常工作
3. **自动化优先** — 能自动的就不要让用户手动操作（下载→归档→刮削全自动）
4. **隐私第一** — 不收集用户数据，不依赖第三方云服务
5. **开源可维护** — 技术栈选开源的，不绑定商业平台

---

## 非目标（明确不做）

- ❌ 不提供在线流媒体播放（不爬取视频源站）
- ❌ 不做社交功能（弹幕、评论、分享）
- ❌ 不依赖任何付费云服务（包括 Plex Pass 等）
- ❌ 不做多用户权限体系（V1 阶段，家庭单用户）

---

## 成功标准

1. 在电视上能用遥控器流畅完成「搜索影片 → 下载 → 观看」全流程
2. 4K HDR 影片在电视上播放不卡顿、不花屏
3. 动漫 ASS 特效字幕能正确渲染
4. 新番更新后能自动下载，回到家打开电视就能看
5. 手机端也能浏览媒体库并播放（非核心场景，可用即可）

---

## 技术约束

- 服务器部署在本地 NAS/Linux，不依赖公网
- 电视是 Android 14 系统，可侧载 APK
- NAS 存储空间需规划 ≥ 4TB 起步
- 家庭网络千兆局域网，不需要公网穿透

## 参考项目

这些是业界已有的优秀项目，Cluo Vision 的目标不是替代它们，而是在它们之上做一个统一的体验层：

| 项目 | 作用 | 我们如何用 |
|------|------|-----------|
| **Jellyfin** | 媒体服务器（管理、转码、播放流） | 核心播放引擎 |
| **Yamby** | Jellyfin 原生 Android TV 客户端 | 视频播放执行者（Intent 深度链接） |
| **Sonarr / Radarr** | 自动化下载管理 | 下载调度引擎 |
| **Prowlarr** | BT/PT 索引聚合 | 资源搜索引擎 |
| **Jellyseerr** | 媒体请求与发现 | 影片发现引擎 |
| **AutoBangumi** | 动漫自动追番 | 动漫专项引擎 |
| **qBittorrent** | BT/PT 下载器 | 下载执行器 |

Cluo Vision App 在这些之上构建统一的 UI 层（找片 + 浏览），播放交给 Yamby，让用户感知不到底层有这么多独立服务。
